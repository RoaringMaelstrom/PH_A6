Project Name: FitLog.


FitLog is an app that helps you track and plan gym workouts. It tranks the time, sets, and calories burned, allowing you to plan smoothly and workout with full effort. 


Technologies used in this project: nextjs, typescript, tailwindcss, react-hot-toast, react-icons, daisyui.

5 Key Features of this project:
- The UI is responsive, tested for mobile, tablet, laptop, and desktop.
- While no direct light/dark button, the site match system settings for appearance
- Exercise count, time, and calories are tracked dymically depending on the ammount added to the list, and updates are easily handled through the context hook.
- Toasts notify the user about their actions being registered.
- Link and Image componenets are used to optimize the loading times.
